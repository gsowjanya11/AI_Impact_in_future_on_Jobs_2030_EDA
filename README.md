# 🤖 AI Impact on Jobs: EDA

An Exploratory Data Analysis (EDA) project investigating how Artificial Intelligence affects employment, risk levels, and salaries across industries.

## 📊 Quick Overview
* **Objective:** Identify high-risk job sectors and shifting skill demands.
* **Key Metrics:** AI replacement risk, salary changes, and remote-work viability.
* **Tech Stack:** Python, Pandas, NumPy, Matplotlib, Seaborn.
